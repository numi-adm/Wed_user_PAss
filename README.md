# 🔐 Credential Splitter (ตัวแยก ชื่อ : รหัสผ่าน)

เว็บแอปพลิเคชันขนาดเล็กสำหรับแยกข้อความรูปแบบ `Username : Password` ออกเป็นตาราง พร้อมปุ่มกดคัดลอกที่รวดเร็วและปลอดภัย

## ✨ คุณสมบัติ
- **Dark Mode**: ดีไซน์โทนมืด ถนอมสายตา
- **รองรับตัวคั่นหลากหลาย**: แยกข้อมูลด้วยเครื่องหมาย `:`, `|` หรือ `;` ได้ในครั้งเดียว
- **คัดลอกรวดเร็ว**: กดคัดลอกทีละช่อง หรือคัดลอกทั้งคอลัมน์ได้ในคลิกเดียว
- **ปลอดภัย 100% (Client-Side)**: โค้ดทำงานบนเบราว์เซอร์ของผู้ใช้ทั้งหมด ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ภายนอก
